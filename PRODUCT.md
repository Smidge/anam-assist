# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Home Assistant users evaluating and installing an unofficial Anam avatar integration.

## Product Purpose

Explain the integration, its cloud dependency and restricted tools, then help users install and try the experimental preview.

## Capabilities and Constraints

Product truth is maintained in README.md and SECURITY.md. Anam handles speech, conversation and avatar media. Home Assistant executes exposed, allowlisted Assist tools. Admin-only browser panel. Read-only by default; opt-in control of lights only. Manual installation verified on HA 2026.10.3. Full HACS lifecycle and physical mobile testing remain incomplete. No official affiliation or security-audit claim.

## Brand Commitments

Anam Assist. User requested the familiar pattern of a Home Assistant community integration site. No Anam or Home Assistant logos are copied.

## Stack

Implementation assumption: static HTML/CSS with a small local JavaScript explanation, deployed through GitHub Pages. No analytics, third-party embeds, API keys or live home connection on the public site.

## Evidence on Hand

50 backend and 36 browser tests passed for the preview. Live portrait, temperature query and owner-confirmed light off/on with restored brightness. Published repository and private vulnerability reporting.
